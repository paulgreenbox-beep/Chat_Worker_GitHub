# Milestones

- **CWG-001 (source foundation):** typed protocol, routing state machine, documentation. Executed local checks and their exact source identity are recorded in [the audit report](../audit/REPORT.md); this does not accept later delivery milestones.
- **CWG-002 (GitHub ingress):** authenticated webhook endpoint, bounded parser, GitHub permission recheck, durable deduplication.
- **CWG-003 (chat binding):** trusted Codex thread registration/resumption, account and generation binding, stale chat refusal.
- **CWG-004 (MCP):** authenticated inbox, read, ack, reply with no unsolicited execution.
- **CWG-005 (reliability):** persistent queue, recovery, correlated status, independent negative tests and end-to-end delivery.
- **CWG-006 (optional):** native source check broker after independent Windows qualification.

No milestones are declared accepted by this document.
